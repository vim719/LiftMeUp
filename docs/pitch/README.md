# Hackathon pitch materials

Materials for the 2-minute hackathon pitch.

- `pitch-sheet.html` is a one-page infographic with the ELI5 explanation, problem, solution, NYC Open Data breakdown, tech stack and beneficiaries. Open it in a browser.
- `deck/` holds the 10-slide pitch deck as a Slides artifact export: `deck.json` is the index and `slides/*.html` is one file per slide (1920x1080 canvas).
- `gemini-presentation-brief.md` is a prompt that tells Gemini how to design the same deck.
