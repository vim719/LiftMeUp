Tech stack

What each tool does in the build

Frontend

React 19, TypeScript, Vite

Ledger, timeline, detail drawer and the AI briefing panel.

Backend

Django 6, REST Framework

Due-date engine and the clients for the NYC endpoints.

Database

PostgreSQL

Stores only the buildings and elevators a manager enters. Status is computed, never stored.

AI

Claude Haiku 4.5

Writes the briefing from ledger rows and fine totals.

Quality

pytest, Vitest, Playwright

Test-first, a 90% coverage gate and accessibility checks.

Delivery

GitHub Actions, Render

CI on every change, then deployed as two services and a database.
